# AI Tutor for Low Resource Course

## About the Project

AI Tutor for Low Resource Course is an AI-based educational system
designed to help students who have limited access to quality learning
materials, internet connectivity, and educational resources.

The system supports self-learning and provides learning assistance
using Artificial Intelligence and Natural Language Processing.

## Objectives

- Provide learning support to students
- Support self-learning
- Provide educational materials
- Support multiple languages
- Help students with limited learning resources
- Improve access to digital education

## Key Features

- AI-based learning assistance
- Multilingual support
- Question and answer system
- PDF learning materials
- Self-learning support
- Simple and user-friendly interface

## Technologies Used

- Python
- Natural Language Processing (NLP)
- NumPy
- Pandas
- Machine Learning
- Database
- HTML, CSS and JavaScript
